Härteliste Scanner – OCR-Version

Änderung:
- Barcode-Scan wurde durch OCR-Scan ersetzt.
- Der grüne Rahmen zeigt den Scanbereich an.
- Status im Kamerabild zeigt: Suche Text / Gelesen / Nichts gefunden / Mehrdeutig.
- Erkennt laufende Nummern direkt. Charges werden nur automatisch abgehakt, wenn sie eindeutig sind.

Nutzung auf GitHub Pages:
1. Alle Dateien in dein Repository laden/ersetzen.
2. index.html und manifest.webmanifest im Hauptordner lassen.
3. Seite über HTTPS öffnen.
4. OCR-Scanner starten und die Nummer groß/scharf in den grünen Rahmen halten.

Hinweis:
OCR braucht Licht, Fokus und möglichst große Zeichen. Kleine oder unscharfe Zahlen unter einem Barcode werden schlechter erkannt als ein Barcode selbst.
